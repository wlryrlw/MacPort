# MacPort

MacPort 是一款面向个人使用的刘海屏 macOS 端口监控应用。它可以检测本机当前被监听或使用的 TCP/UDP 端口，显示对应的进程信息，并通过历史记录和诊断系统帮助用户了解端口状态的变化。


## 功能

- 监控当前的 TCP、TCP6、UDP 和 UDP6 端口，显示端口、协议、地址、连接状态、PID 和进程名称等信息。
- 使用 SQLite 保存永久历史记录，支持历史查询和 JSON/CSV 导出。
- 在菜单栏显示监控状态、最近扫描时间和端口摘要。
- 对扫描失败权限受限、输出格式变化、数据库异常和系统更新不兼容提供稳定错误编号。

## 系统要求

- macOS Tahoe 26.5.1 是当前首版验证基线，应用最低系统版本配置为 macOS 26.0。
- 推荐使用 Apple Silicon，当前构建目标为 `arm64`。
- 首版验证 Build：`25F80`。


## 安装与运行

```
cd MacPort
sh scripts/build_app.sh
open dist/MacPort.app
```
首次运行时，应用会执行兼容性检查，然后出现在菜单栏。点击菜单栏图标可以查看当前端口、扫描状态、历史记录、诊断页面和设置。

## 使用说明

在内置刘海屏上，将鼠标移动到屏幕顶部中央附近可以看到端口摘要。点击摘要可打开详情窗口。外接显示器没有刘海，悬浮提示会回退到顶部中央区域。

默认情况下应用主要显示监听端口，也支持查看全部连接。后台默认扫描间隔为 5 秒，打开详情页时会提高刷新频率；设置页面可以选择 1、5、15 或 30 秒的刷新间隔。

单次扫描默认超时时间为 3 秒。超时后当前子进程会被终止，并生成 `SCAN-003`，不会无限创建后台扫描进程。

应用数据默认保存在：

```text
~/Library/Application Support/MacPort/
├── history.sqlite
└── diagnostics.sqlite
```

## 错误和诊断

典型错误编号包括：

| 编号范围 | 含义 |
| --- | --- |
| `SYS-001` 至 `SYS-006` | 系统版本、架构、资源和能力探测问题 |
| `SCAN-001` 至 `SCAN-008` | `lsof` 缺失、权限、超时、退出码和输出格式问题 |
| `PARSE-001` 至 `PARSE-005` | 端口记录字段、协议或端口号解析问题 |
| `DB-001` 至 `DB-006` | 历史数据库打开、写入、迁移、锁定和导出问题 |
| `DISPLAY-001` 至 `DISPLAY-003` | 显示器和顶部区域信息问题 |
| `OVERLAY-001` 至 `OVERLAY-002` | 悬浮面板创建或定位问题 |


扫描失败时，MacPort 会保留最近一次成功扫描结果，并显示其时间以及“数据可能已过期”状态。用户可以在诊断页面执行重新检查、重新扫描、复制诊断信息或导出诊断报告。
